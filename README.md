# Learny

Личная платформа для подготовки к iOS-интервью и изучения Go. Интерфейс выполнен в монохромном liquid-glass стиле и адаптирован под телефон и десктоп.

## Возможности

- отдельные треки iOS и Go;
- разделы «iOS с нуля», «Go с нуля» и «Подготовка к интервью»;
- добавление собственных разделов с сохранением в `localStorage`;
- поиск по учебным модулям и экран прогресса;
- кодовая лаборатория с реальным запуском Swift и Go;
- адаптивный интерфейс и поддержка `prefers-reduced-motion`.

## Запуск

Требуется Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm test
```

## Запуск кода

Маршрут `/api/run` принимает только Swift и Go, ограничивает исходник 10 КБ и отправляет его в публичный изолированный компилятор Judge0 CE. Не вставляйте в редактор токены, ключи и другие секреты.

Прогресс и пользовательские разделы хранятся локально в браузере текущего устройства.
